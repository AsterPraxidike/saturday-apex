Apex broadcast control

Set broadcast details, paste the weekly token, and edit production staff or screen fields below. Save a section to update the OBS pages live. Shared settings apply across matching screen fields.

Broadcast details — update every screen together

Set a season label and its Week 1 Saturday once. Week numbers advance at Saturday midnight in the broadcast timezone. Before that date, pages show Preseason. Leave automatic counting off for a manual week. Map and results come from Respawn when reachable, or from imported API results. You can still override a map manually between games.

Weekly Respawn token and results

Changing the token clears the previous week’s scores, champion, and map. Python polls Respawn every 30 seconds by default. The map comes from the latest completed game, not the next scheduled game.

Production staff — ending credits

Enter a role and one name per line. Add or remove roles for this broadcast.

Screen settings

Select a screen to edit its text, switches, colors, timers, and lists. Shared settings override matching screen values.
